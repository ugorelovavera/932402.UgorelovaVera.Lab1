# 932402.UgorelovaVera.Lab1
Лабораторная 5 по курсу "web-технологии" ИПМКН ТГУ, 2026 год
Страница создана в учебных целях, как способ освоить базовую структуру HTML-документа и основы CSS, работу с текстом,
форматированными, списками, классами, позиционированием, селекторами, скриптами JS.
На данном этапе был добавлен JS скрипт,  манипулирующий DOM деревом, ищущий элементы, изменяющий содержимое и стили по нажатию кнопки, а также сохраняющий состояние страницы между перезагрузками через localStorage.
Результат: интерактивная страница с динамическим обновлением без перезагрузки, с
сохранением состояния между перезагрузками через localStorage
